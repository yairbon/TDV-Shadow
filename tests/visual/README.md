# Visual regression harness (Phase 3 spec)

Not yet implemented — this is the contract the Phase 3 work implements.

## Determinism preconditions

A screenshot test that is not bit-deterministic is worse than no test. Before any capture:

- Fixture data only: `tests/fixtures/bars-<seed>.json`, generated by a seeded PRNG,
  committed. No network, no clock-dependent data.
- `page.clock.setFixedTime(...)` (or an injected clock) — the chart must never read
  `Date.now()` during a test render.
- Viewport `1280×720`, `deviceScaleFactor: 2` (exercises the DPR path — the most common
  source of blur bugs), `reducedMotion: 'reduce'`, animations disabled.
- Fonts: bundle the metric font locally and `document.fonts.ready` before capture.
  System-font fallback across machines is the #1 cause of false diffs.
- Wait for the app-dispatched `chart:rendered` event. Never `waitForTimeout`.

## Capture

```ts
await expect(page.locator('#chart')).toHaveScreenshot('candles-1m.png', {
  maxDiffPixelRatio: 0.001,
  animations: 'disabled',
});
```

Baselines in `tests/visual/__screenshots__/`. Diffs fail the run; baselines are updated
only by a human running `--update-snapshots` deliberately, never in CI.

## Programmatic spatial assertions (run alongside every screenshot)

Pixels alone don't localise a bug. The renderer exposes a debug geometry dump
(`window.__chartGeometry()`, dev builds only) and the spec asserts:

1. **No horizontal overlap** — for every adjacent pair, `x[i+1] - bw/2 >= x[i] + bw/2 + 1`.
2. **Containment** — every drawn rect lies within the plot rect; nothing bleeds into the
   price or time gutter.
3. **No page overflow** — `document.body.scrollWidth <= document.body.clientWidth` and the
   same for height; the chart never forces a scrollbar.
4. **Transform round-trip** — `|Y⁻¹(Y(p)) - p| < 1e-9` and `|X⁻¹(X(i)) - i| < 1e-9`
   sampled across the visible domain.
5. **Crispness** — the canvas backing store is exactly `round(cssSize * dpr)`; the DPR
   transform matrix is exactly `(dpr, 0, 0, dpr, 0, 0)`.

## Scenario matrix

`candles-1m` · `candles-1d` · `log-scale` · `zoomed-out (s < 3 → line mode)` ·
`zoomed-in (s = 60)` · `single-bar` · `flat-series (pMax == pMin)` · `doji` ·
`with-volume` · `crosshair-at-bar` · `dark-theme` · `dpr-1` vs `dpr-2`.

Chromium is preinstalled at `/opt/pw-browsers`; do not run `playwright install`.
